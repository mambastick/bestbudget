Дата стенда: 23.10.2026. Только отдельная PGlite на 54330 и приложение на 3200; реальные семейные данные не используются.

В демо запускается настоящий seed-скрипт, включая USD-накопления и RUB→USD-перевод. Затем в тестовую БД добавляются
фиксированные записи курсов USD/EUR и ручной приоритет на ту же дату. `FX_PROVIDER=none` исключает внешние запросы:
это демонстрация кеша, ручного ввода и текущей оценки. Дополнительные снимки показывают устаревшие и отсутствующие курсы. Кнопка загрузки ЦБ поэтому отключена.

Воспроизведение из корня репозитория (перед запуском убедиться, что 3200/54330 свободны):

```bash
export TMPDIR=/var/tmp/codex-golodn1y/bestbudget-multicurrency-screenshots
mkdir -p "$TMPDIR"
npx -y pnpm@10.27.0 exec playwright install chromium --only-shell
npx -y pnpm@10.27.0 test:screenshots
```

Тест сам поднимает отдельную БД и production-сервер, создаёт демо-администратора и пространство, вызывает `db:seed-demo`,
проверяет сумму USD-счёта, автоподстановку/редактирование зачисления, русские даты и отсутствие горизонтального скролла.
Также проверяет отсутствие исторического баннера, дедупликацию устаревших курсов в карточке и действие/текст баннера по правам системного администратора.
PNG перезаписываются в этой папке. Если production-сборка уже актуальна, можно задать `E2E_SKIP_BUILD=1`.
Для браузера вне стандартного кеша Playwright задайте `PLAYWRIGHT_BROWSERS_PATH` при установке и запуске одинаково.
