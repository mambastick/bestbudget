# Приёмка ИИ-ассистента

Синтетическая семья, тестовая модель AI SDK, без банковских данных и внешних API. Снимки создаёт `e2e/ai.spec.ts` на production-style тестовой сборке.

- `admin-ru.png` — настройки провайдера и учёт использования.
- `chat-desktop-ru.png`, `chat-desktop-en.png` — desktop 1280px, ru/en.
- `chat-mobile-ru.png`, `chat-mobile-en.png`, `chat-mobile-en-dark.png` — 375px, светлая/тёмная тема, отдельная прокрутка сообщений и поле ввода снизу.

Русские названия категорий — пользовательские данные; они сохраняются после переключения интерфейса на английский. Это браузерные проверки Chromium; реальная экранная клавиатура iOS/Android отдельно не проверялась.
