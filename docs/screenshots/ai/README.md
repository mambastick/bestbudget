# Приёмка ИИ-ассистента

Синтетическая семья, тестовая модель AI SDK, без банковских данных и внешних API. Снимки создаёт `e2e/ai.spec.ts` на production-style тестовой сборке.

- `admin-ru.png` — настройки провайдера и учёт использования.
- `chat-desktop-{ru,en}.png`, `chat-desktop-ru-dark.png`, `chat-desktop-en-light.png` — desktop 1280px, ru/en, обе темы.
- `chat-mobile-{ru,en}.png`, `chat-mobile-{ru,en}-dark.png` — 375px, обе темы; название диалога, лента с отдельной прокруткой и поле ввода у нижнего края.
- `dialogs-mobile-ru.png` — sheet со списком и меню действий каждого диалога.
- `thinking-{ru,en}-{1280,375}.png`, `tools-{ru,en}-{1280,375}.png`, `error-{ru,en}-{1280,375}.png` — ожидание, вызов инструмента и ошибка с кнопкой повтора.

Русские названия категорий — пользовательские данные; они сохраняются после переключения интерфейса на английский. E2E также эмулирует уменьшение visualViewport при открытии клавиатуры и проверяет сохранение позиции после ручной прокрутки вверх. Это браузерные проверки Chromium; реальная экранная клавиатура iOS/Android отдельно не проверялась.
