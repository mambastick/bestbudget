# Импорт — синтетическая браузерная проверка

Скриншоты из `e2e/imports.spec.ts`, Chromium на production standalone-сборке:

- `import-preview-375.png` — 30 строк карточками, компактный степпер, редактирование через sheet, кнопки без перекрытия FAB; проверяется `document.documentElement.scrollWidth <= innerWidth`.
- `import-preview-desktop.png` — те же 30 строк в таблице: 24 новые, один дубль, две стороны перевода, одна плановая и две ошибки. Итоги исключают выбранный перевод и пропуски.
- `import-duplicates-desktop.png` — повтор CSV: 28 дублей / уже учтённых строк, две ошибки, к записи ноль операций.

Данные полностью синтетические: `owner@e2e.test`, PYATEROCHKA и вымышленные покупки/счета/платежи. Кандидаты готовятся только в изолированной базе Playwright на 54330; настоящий `DATABASE_URL` из окружения не используется. Это проверка UI и собственного формата, не приёмка реальной банковской выгрузки.

Браузерный сценарий проходит мастер колонок, фильтры, выбор строк, массовую смену категории/решения, предложение применить категорию к восьми похожим покупкам, диалог правила, мобильный sheet, commit → повтор/дубли → undo. Дополнительные сценарии проверяют XLSX/Origin и показ 205 строк порциями по 100, без изменения категории невыбранных строк. Категория подтверждаемой плановой берётся из существующей операции, даже если банковская подсказка отличается.

Воспроизведение: `npx -y pnpm@10.27.0 test:e2e`; изображения появляются в `work/import-*.png`. Порты 3200/54330 должны быть свободны. Для собственного кеша браузера задайте `PLAYWRIGHT_BROWSERS_PATH` в дисковой временной директории и предварительно выполните `pnpm exec playwright install chromium`.

Локальная проверка 23.10.2026 после rebase на `bc5b2d0` (напоминания + цели + кредиты): `typecheck`, `lint`, `build`, `drizzle-kit check` — успешно; Vitest — 271 тест в 31 файле; Playwright — 15 тестов. Миграция импорта — `0007_statement_import`; миграции main сохранены без изменений. Интеграционные тесты проверяют исключение полного кредитного платежа/его частей и старого черновика, а также однократный учёт перевода в прогрессе цели и его отмену.
