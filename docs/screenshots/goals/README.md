# Цели: мобильная приёмка

Production standalone-сборка, Playwright с Chromium (Brave), viewport 375 × 812.
Данные созданы сценарием `e2e/acceptance.spec.ts` в отдельной in-memory БД на порту 54330.

- `goals-detail-375.png` — цель 300 000 ₽, выполненный перевод 75 000 ₽, прогресс 25%, история и прогноз.
- `goals-list-375.png` — после изменения суммы цели на 75 000 ₽: достигнута, прогресс 100%.

Автоматические проверки ширины выполнены для формы создания, формы пополнения, списка и детальной страницы.
Скриншоты просмотрены вручную; в начале детального снимка видно уведомление об успешном пополнении.
Повторить: `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/путь/к/chromium npx -y pnpm@10.27.0 test:e2e`.
