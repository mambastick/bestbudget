# Скриншоты README — beta.2

Сняты на production standalone, дата демо — 23 октября 2026. Все имена, операции и курсы вымышлены.
Светлые скриншоты: обзор целиком, календарь и ипотека (desktop-вьюпорт 1280×960), цели (375×1000).
Для снимка целей экран выше, чтобы плавающая кнопка не перекрывала содержимое третьей карточки; узкий сценарий 375×812 дополнительно покрыт e2e.
Календарь и цели имеют тёмные варианты; GitHub выбирает их по теме браузера через `<picture>`.

Воспроизведение из корня репозитория:

```bash
npx -y pnpm@10.27.0 exec playwright install chromium
npx -y pnpm@10.27.0 test:screenshots readme.spec.ts
```

Нужны свободные **3200/54330**. Сценарий создаёт временную PGlite-БД, администратора, пустую RUB-семью
и запускает настоящий `scripts/seed-demo.ts`. `FX_PROVIDER=none`, `JOBS_ENABLED=false`: сетевые курсы и доставка
не используются. Курсы USD=95 RUB, EUR=100 RUB — синтетические. Повтор seed отклоняется без добавления данных.
Даты seed считаются относительно «сегодня» в часовом поясе семьи; для новых скриншотов закреплённая дата не требуется.

Проверяется 22 маршрута/вкладки × 1280/375 px × светлая/тёмная тема = **88 состояний**:
обзор, операции, регулярные, мастер импорта, календарь, бюджеты, цели, кредиты, создание кредита, аналитика, счета,
все вкладки настроек и админки, детали ипотеки и цели. Сценарий проверяет ширину документа, отсутствие
видимых ISO-дат, ошибок браузера, обрезки подписей осей X/Y, запятую в анимированном балансе и единственную подпись «Без срока».
Полные снимки и JSON-аудит прикладываются к результатам в `work/playwright-screenshots/` (не в Git).
В README показываются четыре выбранных снимка (два с тёмными вариантами); анимации отключены для воспроизводимости.

Полировка по визуальному просмотру и ревью кода:

- растянутые ссылки целей/календаря: `CardAction` и компактные кнопки;
- пустота под графиком баланса: карточки выровнены по верхнему краю;
- обрезка подписей денежных осей: ширина 80 px на общих графиках, целях и кредитах;
- обрезка названий категорий на desktop: меньший донат и более широкая легенда с переносами;
- точка вместо запятой в копейках анимированной суммы;
- повтор «Без срока» в карточке цели;
- ось многолетнего графика кредита без года;
- дробная ставка в событиях кредита без русской десятичной запятой.

Горизонтального скролла **страницы**, наездов и ISO-дат на проверенном наборе не найдено.
Локальная прокрутка табов и административной таблицы на телефоне сохранена.
Доставка уведомлений на настоящее устройство, банковские форматы, живой OIDC и Docker/OCI-установка этим сценарием не проверяются.
