# Счета, кредиты, цели и импорт — ru/en

Сценарий `e2e/assets-i18n.spec.ts` создаёт отдельного синтетического пользователя и пустую семью, запускает настоящий `scripts/seed-demo.ts` в изолированной БД Playwright. Данные владельца приложения не используются.

Матрица: **ru/en × 1280/375 px × light/dark**. В каждой комбинации проверяются `/accounts`, `/loans`, `/loans/new`, детальная страница кредита, `/goals`, детальная страница цели, мастер импорта и сохранённый предпросмотр. Дополнительно открываются формы счёта, цели и досрочного погашения. Проверяется отсутствие горизонтального переполнения и ошибок браузера.

Сохранённые английские кадры:

- `loans-en-desktop-dark.png` — кредит, график и симулятор, 1280 px, dark.
- `goal-en-375-light.png` — цель, прогноз и история, 375 px, light.
- `import-en-375-dark.png` — предпросмотр с проведённой, ожидающей и отклонённой строками, 375 px, dark.

Английский сценарий также создаёт счёт с дробной суммой, подтверждает и отменяет импорт, выполняет пополнение цели и проверяет английское сгенерированное название в БД. Один и тот же черновик открывается в ru и en. Русские имена счетов, целей и кредитов в кадрах — пользовательские данные seed-demo, они не переводятся.

Технические границы:

- Новые предупреждения, причины решений и подписи кандидатов импорта сохраняются как `bb-import:` + JSON с `code`/`params`. Типы полей БД не меняются; миграция не требуется. Старые русские сообщения распознаются по известным шаблонам словаря и переводятся при отображении; неизвестный текст сохраняется.
- `bank-data.json` содержит исходные заголовки и маркеры русскоязычных CSV-форматов. Это данные протокола чтения, а не подписи интерфейса.
- Сервисы получают активную локаль через контекст запроса. При фоновой материализации кредитов используется сохранённая локаль создателя; если она не задана или создатель удалён — `en`, как системный fallback приложения. Старые названия операций и категорий не переименовываются.
- Общие формы операций и общие предупреждения курсов переводятся другими областями фазы 2. Этот PR не меняет их UI.
- `use-intl` добавлен как прямая зависимость для чистого `use-intl/core`; версия уже присутствовала в lockfile как зависимость `next-intl`. Это позволяет запускать seed-demo и доменные сервисы с `--conditions=react-server` без загрузки клиентских React hooks.

Форматирование валют использует `currencyDisplay: "narrowSymbol"`: английские суммы и суффиксы MoneyInput показывают `₽`, `$`, `€`, `¥`. Числовые сокращения графиков (`6M`, `4.5M`) сохраняются.
