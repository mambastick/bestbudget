# Администрирование ru/en

Только синтетические пользователи и данные `scripts/seed-demo.ts`. Воспроизведение: `pnpm test:e2e admin-i18n.spec.ts` (порты 3200/54330 должны быть свободны).

`e2e/admin-i18n.spec.ts` проверяет шесть вкладок: пользователи, пространства, авторизация/SSO, курсы валют, события и уведомления. Для каждой — ru/en × 1280/375px × light/dark (48 состояний), metadata, язык документа, отсутствие горизонтального скролла страницы и ошибок браузера. Переключение языка использует реальную настройку профиля; отдельно проверяется сохранение `last_seen_locale` без изменения пользовательских названий.

В репозитории сохранены три английских примера:

- `users-en-1280-light.png` — пользователи, desktop/light.
- `auth-en-375-dark.png` — способы входа и SSO, mobile/dark.
- `notifications-en-375-light.png` — Telegram, Web Push и синтетическая ошибка доставки, mobile/light.

Все 48 снимков доступны в output-каталоге Playwright во время локального прогона. Проверки не подключают настоящие SMTP, Telegram или push-провайдеры; локаль фоновых сообщений, писем, ошибок callback и меню команд проверяется unit/integration с подменёнными транспортами.
