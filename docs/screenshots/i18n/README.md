# Язык и тема, фаза 1

Синтетический пользователь Alex Demo, изолированная БД e2e, без реальных финансовых данных. Каркас/auth/settings переведены; названия семьи и категорий — сохранённые данные, финансовые экраны ждут фазы 2.

- `login-en.png`, `login-ru.png`: вход на обоих языках, 1280×900.
- `menu-language-desktop.png`, `menu-theme-desktop.png`: radio-подменю пользователя, 1280×900.
- `menu-language-375.png`, `menu-theme-375.png`: те же подменю в мобильной панели, 375×812.

Воспроизведение: `npx -y pnpm@10.27.0 test:e2e e2e/i18n.spec.ts`. Тест запускает production standalone, использует только 3200/54330 и перезаписывает эти изображения. Проверяет системный язык, явный выбор, сохранение после reload, тёмную тему и системную схему через `emulateMedia`.

Локальная проверка Chromium: `typecheck`, `lint`, `build`, `i18n:check` успешны; Vitest 297/297, production Playwright 16/16. В тесте i18n нет page/console errors, проверяется первый кадр после reload с тёмной темой, radio-семантика, открытие меню клавиатурой и отсутствие горизонтального скролла. В общих отрицательных OIDC-сценариях Better Auth пишет ожидаемые отказы в серверный лог.
