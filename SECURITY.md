# Security policy

Only the latest published beta release receives security fixes. Please upgrade
before checking whether an issue still occurs.

Report suspected vulnerabilities through GitHub
[Private vulnerability reporting](https://github.com/mambastick/bestbudget/security/advisories/new).
Do not disclose them in public issues or pull requests. Include the affected
version, installation method, impact and reproduction steps using synthetic data.

Security issues include authentication or permission bypasses, access to another
household's data, secret exposure, injection, XSS, SSRF and remote code execution.
Use ordinary issues for feature requests and bugs without a security impact.
Never attach real bank statements, financial data, credentials or database dumps.

О подозрениях на уязвимость сообщайте конфиденциально через
[GitHub Private vulnerability reporting](https://github.com/mambastick/bestbudget/security/advisories/new),
а не в публичных issues. Укажите версию, способ установки, последствия и шаги
воспроизведения только на синтетических данных. Поддерживается последняя
опубликованная бета; не прикладывайте реальные выписки, финансовые данные или секреты.
